## P2 · 现状痛点

**页面类型**: 问题页
**叙事功能**: 建立共鸣（Why）

### 文案

**标题**: 传统水质监测，三大痛点制约管理效能

**痛点1：数据滞后**
- 人工采样周期 24-48 小时
- 错过最佳处理时机
- 污染事件事后追溯，难以主动防控

**痛点2：可视化差**
- 数据分散在 Excel、纸质报表
- 无法快速判断水质状态
- 领导汇报时缺乏直观展示手段

**痛点3：响应慢**
- 异常发现依赖人工巡检
- 从发现问题到上报平均 4-6 小时
- 被动应对，错失处置窗口

### 数据支撑
- 引用：环保部门调研显示，70% 基层河长希望获得实时水质数据

### 设计提示
- 三个痛点用图标 + 简短文字呈现
- 色调偏压抑（灰蓝色），暗示问题严重性
- 可用"断裂的时间轴"视觉隐喻数据滞后

## P3 · 政策与市场驱动

**页面类型**: 背景页
**叙事功能**: 强化必要性

### 文案

**标题**: 政策加码 + 市场刚需，智慧水务势在必行

**政策侧**
- 《水污染防治行动计划》要求重点流域实时监控
- 河长制考核：水质达标率纳入政绩指标
- "十四五"规划：智慧环保投入年增 15%

**市场侧**
- 智慧水务市场规模：2024 年达 180 亿元
- 年复合增长率 12.3%
- 移动端监测需求增速最快（年增 25%）

**需求侧**
- 基层河长：日常巡检需实时数据支撑
- 水务管理人员：会议汇报需直观展示
- 公众/媒体：环境知情权要求信息透明

### 设计提示
- 左侧政策图标（文件/公章），右侧增长曲线
- 色调开始转亮，从压抑过渡到希望

## P5 · 核心功能展示

**页面类型**: 功能页
**叙事功能**: 功能亮点

### 文案

**标题**: 五大指标实时监测，一站掌握水质全貌

**指标卡片**

| 指标 | 正常范围 | 超标阈值 | 监测意义 |
|------|----------|----------|----------|
| pH 值 | 6.5 — 8.5 | < 6.5 或 > 8.5 | 影响水生生物生存 |
| 溶解氧 | ≥ 5.0 mg/L | < 5.0 | 反映水体自净能力 |
| 浊度 | ≤ 10 NTU | > 10 | 反映悬浮颗粒物 |
| 氨氮 | ≤ 1.0 mg/L | > 1.0 | 有机物污染标志 |
| 站点状态 | 五级分级 | 最差因子法 | 综合评估 |

**站点覆盖**
- 5 个监测站点：青龙溪上游 / 红旗镇段 / 蓝河市段 / 黄石工业园段 / 碧水湾入江口
- 地图分布：一目了然掌握全局

**历史趋势**
- 近 7 天 / 30 天数据变化
- 折线图展示，支持多指标对比

### 设计提示
- 5 个指标卡片横向排列（或 2+3 布局）
- 正常 = 绿色，警告 = 黄色，危险 = 红色
- 预留趋势图版式空间

## P6 · 技术架构

**页面类型**: 技术页
**叙事功能**: 技术可信度

### 文案

**标题**: 轻量技术栈，快速部署，低维护成本

**技术选型**（引用 PRD 第 6.1 节）
- 前端框架：Vue 3.4（Composition API）
- 引入方式：CDN 单页面，无需构建工具
- 图表库：ECharts 5.5（按需加载，首屏 ~90KB）
- 图标：Font Awesome 6
- CDN 源：BootCDN（国内）/ jsDelivr（全球）双源 fallback

**性能表现**（引用 @bobo 优化方案）
- 首屏加载：FCP ≤ 1.5s（4G 网络）
- 包体积：~250KB（gzip）
- 骨架屏：感知加载 < 1s
- 关键 CSS 内联，消除渲染阻塞

**部署优势**
- 单 HTML 文件，所有资源 CDN 引入
- 零服务器成本（Vercel/Netlify 免费 tier）
- 后续可平滑对接真实 API

### 设计提示
- 架构图：Vue 3 + CDN → ECharts → 浏览器
- 性能数据用大号字体突出
- 技术栈 logo 排列

## P7 · 数据可视化亮点

**页面类型**: 亮点页
**叙事功能**: 差异化优势

### 文案

**标题**: 专业级可视化设计，数据一目了然

**指标仪表盘**
- pH：红→绿→紫渐变，直观反映酸碱度
- 溶解氧：蓝→青 + 气泡动画，生动展示含氧量
- 浊度：清澈蓝→浑浊棕，颜色即含义
- 氨氮：安全绿→超标红，阈值警示
- 站点状态：脉冲灯 + 呼吸动画，状态感知

**趋势图表**
- 折线图：近 7 天 / 30 天切换
- 多指标对比：同一图表叠加分析
- 异常标注：超标点自动高亮

**交互设计**
- 下拉刷新：实时获取最新数据
- 双指缩放：图表细节查看
- 站点滑动：横向切换监测点

### 设计提示
- 展示 2-3 个典型图表 mockup
- 突出颜色编码的直观性
- 交互手势图标示意

## P9 · 预期价值

**页面类型**: 价值页
**叙事功能**: 价值升华（What）

### 文案

**标题**: 从"事后追溯"到"实时预警"，管理效能全面升级

**效率提升**
- 监测时效：从"日报"提升到"实时"

- 维护简单：单页面应用，更新只需替换文件
