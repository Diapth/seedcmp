## 1. 设计原则

### 1.1 核心原则

- **信息优先**：数据可读性 > 视觉装饰，每页遵循"3秒法则"
- **移动端优先**：所有设计决策以 375px 基准宽度为起点
- **状态即语言**：通过颜色直观传递水质状态，无需阅读文字即可感知
- **呼吸感**：信息密度高的页面加大留白，避免压迫感

### 1.2 情绪曲线

```
P1-P3（问题段）: 压抑  →  P4-P7（方案段）: 明亮  →  P8-P10（价值段）: 振奋
   冷灰背景              湖蓝主色主导            渐变+上升视觉
```

| 名称 | 色值 | 用途 | 情绪映射 |
|------|------|------|----------|
| **深靛蓝** | `#0A2540` | 标题文字、关键数据 | 专业、可信 |

## 7. 移动端适配规范

### 7.1 断点定义

| 断点 | 宽度 | 设备类型 | 布局策略 |
|------|------|----------|----------|
| **xs** | < 375px | 超小屏 | 单列，紧凑间距 |
| **sm** | 375px - 428px | 手机 | 单列，标准间距 |
| **md** | 429px - 767px | 大屏手机 | 单列，宽松间距 |
| **lg** | 768px - 1023px | 平板 | 双列，侧边导航 |
| **xl** | ≥ 1024px | 桌面/投屏 | 多列，完整导航 |

### 7.2 触控约束

| 元素 | 最小尺寸 | 热区 |
|------|----------|------|
| 按钮 | 44×44px | 48×48px |
| 图标按钮 | 40×40px | 48×48px |
| 列表项 | 56px 高 | 全宽 |
| 图表数据点 | 8px 直径 | 12px 直径 |
| 滑块 | 44px 高 | - |

### 7.3 信息展示约束

| 场景 | 约束 | 替代方案 |
|------|------|----------|
| 单屏指标数 | ≤5个 | 横向滑动或 2×3 网格 |
| 图表 X 轴标签 | ≤6个 | 倾斜 45° 或省略 |
| 图例项数 | ≤4个 | 交互图例（点击展开） |
| 表格列数 | ≤3列 | 横向滚动或卡片化 |
| 文字行宽 | ≤35 中文字符 | 换行或截断+展开 |
| 弹窗高度 | ≤80% 屏幕 | 全屏模态 |

## 8. 动画规范

### 8.1 过渡时长

| 场景 | 时长 | 缓动函数 |
|------|------|----------|
| 按钮悬停 | 150ms | ease-out |
| 卡片悬停 | 200ms | ease-out |
| 页面切换 | 300ms | ease-in-out |
| 图表动画 | 300ms | ease-out |
| 模态框出现 | 250ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 数据刷新 | 200ms | ease-in-out |

### 8.2 加载状态

| 场景 | 方案 |
|------|------|
| 页面加载 | 骨架屏（灰色脉冲块） |
