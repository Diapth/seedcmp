## 1. 项目背景与目标

### 1.1 背景
水环境质量监测是环境保护的核心工作之一。传统水质监测数据分散在各类政府数据库中，缺乏统一、直观、实时的可视化展示手段，导致：
- 环保人员难以快速掌握多站点水质状况
- 公众无法便捷获取身边水体的实时质量信息
- 应急响应时数据获取滞后

### 1.2 目标
构建一个**轻量级、移动端优先**的河流水质数据看板，通过对接美国地质调查局（USGS）NWIS 公开 API，实现：
- 实时展示指定监测站点的水质指标
- 提供历史数据趋势参考
- 支持移动端随时随地查看
- 完全基于真实公开数据，零模拟、零伪造

## 3. 功能需求

### 3.1 核心功能

#### FR-001 实时水质数据展示
- **描述**：展示指定 USGS 站点的最新水质监测数据
- **优先级**：P0
- **验收标准**：
  - 页面加载后自动获取 USGS NWIS 即时值数据
  - 显示站点名称、监测时间、各指标数值
  - 数据更新时间戳清晰可见
  - 加载状态、错误状态、空态均有 UI 反馈

#### FR-002 水质指标卡片
- **描述**：以卡片形式展示各水质指标
- **优先级**：P0
- **指标清单**：
  | 指标 | 参数码 | 单位 | 正常范围参考 |
  |-----|--------|------|------------|
  | pH 值 | 00400 | 无量纲 | 6.5 - 8.5 |
  | 溶解氧 (DO) | 00300 | mg/L | ≥ 5.0 |
  | 浊度 | 63680 | NTU | ≤ 4.0 |
  | 氨氮 | 00608/00610 | mg/L | ≤ 0.5 |
  | 站点状态 | - | 综合评估 | 正常/警告/危险 |

#### FR-003 数据真实性保障
- **描述**：确保所有展示数据来自真实 API，禁止模拟
- **优先级**：P0
- **验收标准**：
  - 所有数据必须来自 USGS NWIS API 实时调用
  - API 不可用时显示 "N/A" 并解释原因
  - 禁止任何形式的 mock、模拟、估算或占位数据
  - 页面须标注数据来源及获取时间

#### FR-004 移动端适配
- **描述**：确保在移动设备上良好的阅读体验
- **优先级**：P0
- **验收标准**：
  - 响应式布局，适配 320px - 1920px 屏幕宽度
  - 触控友好的交互元素（最小 44x44px）
  - 字体大小在移动端可读（≥14px）
  - 支持横竖屏切换

#### FR-005 历史趋势展示（P1）
- **描述**：展示近期水质指标变化趋势
- **优先级**：P1
- **验收标准**：
  - 提供最近 7 天 / 30 天数据趋势图
  - 使用折线图展示各指标变化
  - 支持指标切换

### 3.2 非功能性需求

| 需求 | 描述 | 优先级 |
|-----|------|--------|
| 性能 | 首屏加载 ≤ 3 秒 | P0 |
| 可用性 | 支持离线缓存最近数据 | P1 |
| 可访问性 | 符合 WCAG 2.1 AA 标准 | P1 |
| 兼容性 | 支持 Chrome、Safari、Firefox 最新两版 | P0 |

## 4. 数据规范

### 4.1 数据源
- **主数据源**：USGS National Water Information System (NWIS)
- **API 类型**：即时值服务 (Instantaneous Values Service)
- **数据格式**：JSON

### 4.2 主监测站点
- **站点编号**：01304562
- **站点名称**：PECONIC RIVER at COUNTY HWY 105 at RIVERHEAD, NY
- **位置**：纽约州 Riverhead 县道 105 号佩科尼克河
- **坐标**：40.9220° N, 72.6934° W

### 4.3 API 接口规范

#### 即时值查询
```
GET https://waterservices.usgs.gov/nwis/iv/
  ?format=json
  &sites=01304562
  &parameterCd=00010,00095,00300,00400,63680
  &siteStatus=all
```

**参数码对照表**：
| 参数码 | 参数名称 | 单位 |
|-------|---------|------|
| 00010 | 水温 | °C |
| 00095 | 比电导率 | μS/cm |
| 00300 | 溶解氧 | mg/L |
| 00400 | pH 值 | 无量纲 |
| 63680 | 浊度 | NTU |

> **注意**：氨氮 (NH₃-N) 在 USGS 即时值 API 中可用参数码为 00608 或 00610，但部分站点可能不提供该参数。若 API 未返回，页面须显示 "N/A" 并说明 "该站点当前未提供氨氮监测数据"。

### 4.4 数据真实性约束

**硬性规则**：
1. ✅ 所有展示数据必须来自 USGS NWIS API 实时响应
2. ✅ API 返回 null / 缺失时显示 "N/A"
3. ✅ 页面必须标注 "数据来源：USGS NWIS" 及最后更新时间
4. ❌ 禁止使用 mock 数据、随机数、估算值、占位符
5. ❌ 禁止在 API 失败时显示虚假数据
6. ❌ 禁止对未返回的指标编造数值

**缺失数据处理**：
| 场景 | 处理方式 |
|-----|---------|
| API 返回参数但值为 null | 显示 "N/A" |
| API 未返回某参数 | 显示 "未返回" + 解释该站点不支持 |
| API 请求失败 | 显示错误提示 + 重试按钮 |
| 网络超时 | 显示缓存数据（如有）+ 超时提示 |

## 5. 设计规范

### 5.1 视觉风格
- **主题色**：水蓝 (#2196F3) + 深青 (#006064)
- **状态色**：
  - 正常：#4CAF50（绿）
  - 警告：#FF9800（橙）
  - 危险：#F44336（红）
  - N/A：#9E9E9E（灰）
- **字体**：系统默认无衬线字体栈
- **圆角**：卡片 12px，按钮 8px

### 5.2 布局原则
- 移动端：单列卡片流，垂直滚动
- 平板：双列网格
- 桌面：三列网格 + 侧边信息栏

### 5.3 交互规范
- 数据卡片点击展开详情
- 下拉刷新获取最新数据
- 指标卡片支持左右滑动切换（移动端）

## 7. 验收标准

### 7.1 功能验收
- [ ] 页面能成功加载并显示 USGS 01304562 站点数据
- [ ] pH、溶解氧、浊度、氨氮、站点状态 5 项指标均有展示
- [ ] 数据为实时 API 返回，非模拟数据
- [ ] API 缺失指标正确显示 "N/A" 或 "未返回"
- [ ] 移动端（iPhone SE / Pixel 5）显示正常
- [ ] 数据加载、错误、空态均有 UI 反馈

### 7.2 性能验收
- [ ] 首屏加载时间 ≤ 3 秒（4G 网络）
- [ ] API 数据获取时间 ≤ 5 秒
- [ ] 页面大小 ≤ 500KB（不含外部 CDN）

## 8. 风险与应对

| 风险 | 影响 | 概率 | 应对措施 |
|-----|------|------|---------|
| USGS API 不稳定 | 高 | 中 | 实现缓存机制 + 错误提示 + 重试 |
| 站点 01304562 下线 | 高 | 低 | 准备备用站点列表 |
| 氨氮数据缺失 | 中 | 高 | 明确标注 N/A + 解释原因 |
| 跨域限制 | 中 | 低 | USGS API 支持 CORS |
