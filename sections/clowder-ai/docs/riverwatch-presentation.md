## Slide 2: 项目背景

### 为什么需要水质监测看板？

- **数据分散**：水质监测数据分散在各类政府数据库，缺乏统一展示
- **响应滞后**：环保人员难以快速掌握多站点实时水质状况
- **公众知情权**：普通民众无法便捷获取身边水体质量信息
- **应急需求**：污染事件响应时数据获取速度慢

> 💡 **核心洞察**：公开水质数据很多，但"看得懂、随时看"的工具很少

## Slide 4: 技术方案

### 架构：极简、零依赖、即开即用

```
用户浏览器 ──→ Vue 3 (CDN) ──→ USGS NWIS API
                ↓
           Tailwind CSS (CDN)
                ↓
         单 HTML 文件，直接打开
```

**技术选型理由**：
- **Vue 3 CDN**：无构建工具，开发效率高
- **Tailwind CSS**：快速响应式布局
- **USGS API**：权威公开数据源，免费稳定
- **静态托管**：GitHub Pages / Vercel，零成本部署

## Slide 5: 数据规范 — 真实数据承诺

### 我们的数据原则

✅ **全部真实**
- 所有数据来自 USGS NWIS 实时 API
- 标注数据来源及获取时间

❌ **绝不伪造**
- 禁止 mock、模拟、估算、占位
- API 缺失 → 显示 "N/A"
- 参数未返回 → 显示 "未返回" + 解释
