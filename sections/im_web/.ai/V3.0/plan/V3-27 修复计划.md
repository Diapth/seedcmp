# V3-27 修复计划

## Summary
修复两个回归：会话右键删除要即时、可回滚、可持久屏蔽旧同步结果；新增猫猫的角色模板要来自 Clowder 模板目录，而不是只筛 `source === 'disconnected'` 的联系人。

## Key Changes
- 在 `conversationStore` 增加按当前用户 scoped 的 deleted tombstone 存储，例如 `im-web:deleted-conversations:{uid}`，记录 `lastMsgSeq`、`lastMsgTime`、`deletedAt`。
- `deleteConversation()` 改为乐观删除：
  - 普通 direct/group 调 `syncApi.deleteConversation`；失败时恢复原会话、移除 tombstone，并向调用方抛错。
  - `clowder_ai`、`clowder_cat:*`、本地机器人会话走 durable local delete，不调用后端，返回 local-only 结果。
- 所有恢复入口统一尊重 tombstone：`syncConversations`、`ensureGroupConversations`、`prefetchMissingGroupConversationSummaries`、`ensureConversation`、message history summary。
  - 旧同步结果不重建会话。
  - 新消息 `seq/time` 大于 tombstone 时清除 tombstone 并重建。
- `ConversationList.vue` 引入 Arco `Message`：
  - 删除成功显示成功提示。
  - local-only 删除显示“已删除本地会话”。
  - 后端失败显示错误并保持/恢复当前会话，不静默失败。

## API / Types
- 新增前端类型：
  - `ConversationDeleteResult { ok: true; localOnly: boolean }`
  - `DeletedConversationRecord { lastMsgSeq: number; lastMsgTime: number; deletedAt: number }`
  - `ClowderCatRoleTemplate`
- 扩展 Clowder cat directory contract：
  - `/v1/clowder/cats` 返回 `agents` 继续作为可连接/已连接猫猫联系人。
  - 同时返回 `templates`，来自 Clowder `/api/cat-templates`，包含 `roleTemplateId/catId/displayName/personalitySummary/capabilitySummary/cloneable/unavailableReason`。
- `useClowderStore` 增加 `catRoleTemplates`，由 `response.templates` 优先填充，并兼容旧响应中 `source === 'disconnected'` 的模板候选。
- `ClowderCatConsolePage.vue` 的 `roleTemplateOptions` 改用 `clowderStore.catRoleTemplates`，不再用 `catContactDirectory.filter(source === 'disconnected')`。

## Assumptions
- Backend delete failures for non-local conversations should rollback rather than leave a local-only delete.
- Clowder/direct cat virtual conversations are allowed to use durable local delete because they may not have a backend recent row.
- Role templates are cloneable by default unless upstream explicitly marks them unavailable or non-cloneable.
