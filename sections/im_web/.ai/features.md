# TangSengDaoDaoWeb Vue 重构核心功能设计文档

> **定位**: 基于 Vue 3 的即时通讯 (IM) 网页端重构功能矩阵 (完全对齐原 React 版本功能)

---

## 1. 登录与注册模块 (Login & Register)

### 1.1 手机验证码登录与注册
- **区号选择**: 默认支持 `+86`，支持输入多国手机号（测试环境前缀 `0086`）。
- **发送验证码**: 支持 60 秒倒计时交互，本地环境统一输入测试验证码 `123456` 即可登入。
- **注册流程**: 当账号未注册时，支持输入昵称等基本资料并快速完成自注册。

### 1.2 二维码扫码登录
- **动态二维码**: 主动调用 `/user/loginuuid` 生成 UUID 二维码并展示在登录页上。
- **状态流转**: 
  - 扫码前，提示“请用手机客户端扫码”。
  - 手机扫描后，状态切换为“已扫描，请在手机上确认授权”，展示扫码人头像。
  - 手机确认后，系统自动完成 Token 注入并平滑切入 IM 主控制台。
  - 二维码超过 5 分钟未扫，覆盖“二维码已失效，点击刷新”提示。

## 2. 核心即时通讯模块 (IM Chat Core)

### 2.1 会话列表 (Recent Session List)
- **会话投影**: 监听 SDK 会话事件，会话按最后一条消息的 timestamp 进行倒序排列。
- **快捷键与操作**: 支持右键打开操作气泡：
  - **置顶聊天**: 置顶项始终保持在最顶部，背景色轻微变化提示。
  - **免打扰**: 免打扰会话在收到新消息时不播放提示音，列表徽章展示为灰色未读圆点。
  - **清除未读数**: 双击或右键菜单一键将未读计数置零。
- **草稿暂存**: 输入框未发送内容切走后，列表中该会话名次不变，消息预览区红色展示 `[草稿] 刚才输入的内容`。

### 2.2 聊天窗口与多样化消息 (Chat Room & Messages)
- **核心消息流**: 聊天展示区分左右版面。支持以下消息类型：
  - **文本与表情**: Emoji 面板、快捷 @ 功能、文本格式化。
  - **图片与 Gif**: 支持复制粘贴/拖拽图片直接发送，提供卡片缩略图以及大图点击灯箱放大。
  - **文件与语音**: 气泡内直观展示文件图标、大小及下载进度；语音消息支持点击播放，带有动态音频波纹。
  - **系统提示**: 退群、加群、消息撤回等系统控制帧，以居中淡灰色系统条优雅展现。
- **右键上下文菜单**:
  - **复制**: 复制当前选中的文本消息内容。
  - **回复**: 气泡顶部引用被回复的消息，点击引用框可平滑滚动定位到原消息位置。
  - **多选**: 激活底部多选控制栏，支持消息合并转发或逐条删除。
  - **撤回**: 发出 2 分钟内的消息提供“撤回”选项，点击直接广播撤回通知并替换为系统级已撤回提示。

## 3. 联系人与群组模块 (Contacts & Group)

### 3.1 好友管理 (Friend Relationship)
- **新朋友列表**: 接收到的好友申请聚合，提供同意/拒绝操作，拥有全局未读申请条数红标。
- **好友申请闭环**: 支持发起申请、同意、拒绝、删除申请记录，并通过 `friendRequest` CMD 刷新新朋友列表。
- **拼音首字母检索名册**: 好友按 A-Z 分类，支持好友搜索、快捷备注修改、加入/移出黑名单、删除好友关系。
- **好友资料动作**: 从用户资料页可进入单聊、查看短号/关系状态、设置备注、拉黑、投诉、删除好友。

### 3.2 群组管辖 (Group Management)
- **保存的群聊**: 用户保存到通讯录的群聊列表，点击一键跳转到聊天。
- **群设置侧边栏**: 聊天窗口右上角展开抽屉：
  - **成员管理**: 网格化展示群成员，支持添加/删除群成员。
  - **群资料管理**: 修改群名、编辑发布群公告、查看群二维码、上传群头像、保存/取消保存到通讯录。
  - **群主特权**: 禁言特定成员、全员禁言、设置群内黑名单、任免管理员、群主转让、解散群聊。
  - **邀请确认**: 群二维码和成员邀请需要支持邀请确认页、扫码入群、H5 确认邀请等原项目流程。
- **群聊清理与投诉**: 支持清空群聊天记录、群投诉入口、群成员移除后的系统消息提示。

## 4. 消息增强与媒体能力 (Message Enhancements)

### 4.1 消息类型与内容能力
- **原项目消息类型覆盖**: 除文本、图片、语音、Gif、文件外，还需支持小视频、位置、名片、合并转发、Lottie 贴图、群系统消息、加入组织消息、截图消息和自定义消息。
- **群 @ 与提醒项**: 支持群 @ 消息、成员邀请提醒、服务端控制的列表提醒项，并能点击提醒定位到原消息。
- **消息回复与转发**: 支持引用回复、逐条转发、合并转发，转发时保留原作者和原消息内容。
- **消息收藏**: 文本和图片消息可收藏；收藏列表、添加收藏、删除收藏需保持与原 React Web 的数据源接口兼容。
- **消息编辑与删除**: 支持文本消息编辑、单向删除、双方删除、清空频道消息，以及撤回后的系统提示替换。

### 4.2 消息状态、回执与反应
- **发送状态**: 消息发送中、发送成功、失败重发、弱网断线恢复后的补拉和状态修正需在气泡侧完整体现。
- **语音已读**: 语音消息播放后触发已读上报，并在 UI 中清除未读语音状态。
- **已读回执**: 支持消息已读上报和消息回执列表展示。
- **消息回应**: 支持添加/取消 reaction，并通过增量同步刷新反应状态。
- **置顶消息**: 群聊或频道内可置顶消息、同步置顶消息、清空置顶消息。

### 4.3 搜索、贴图与文件
- **全局搜索**: 支持按关键字搜索用户、群和消息；文件搜索按消息类型筛选文件消息。
- **频道内消息搜索**: 支持按发送者、频道、消息类型、时间范围、topic 分页搜索。
- **文件上传**: 图片、Gif、语音、文件、小视频等媒体消息通过 `file/upload` 获取上传地址并上报上传进度。
- **贴图面板**: 除基础 Emoji 外，还需支持服务端贴图分类、Lottie 贴图和贴图文件预览。
- **敏感词/违禁词同步**: 启动后同步服务端敏感词与违禁词配置，输入和发送前按原项目规则处理。

## 5. 我的、安全与客户端设置 (Me, Security & Settings)

### 5.1 个人资料
- **个人信息编辑**: 支持昵称、性别、短号、头像上传与头像缓存刷新。
- **我的二维码**: 支持展示个人二维码，扫码后可进入用户资料或好友申请流程。
- **官方/客服/访客标识**: 频道资料中需展示服务端下发的用户分类、机器人标识、官方账号标识和访客标识。

### 5.2 安全与隐私
- **黑名单**: 支持黑名单列表、拉黑、解除拉黑，并在资料页和会话设置中同步状态。
- **聊天密码与锁屏**: 支持设置聊天密码、锁屏密码、自动锁屏时间、关闭锁屏密码。
- **账号安全**: 支持修改登录密码、忘记密码、注销账号验证码与注销账号流程。
- **Web3 登录辅助**: 原服务端支持 Web3 公钥、验证文本和签名验证；重构时应保留接口适配位。

### 5.3 设备与通知
- **设备管理**: 支持登录设备列表、查看设备详情、强退设备、安全退出当前登录。
- **Web/PC 登录状态**: 显示 Web 登录状态，支持 PC 端退出登录和被踢下线后的本地登出。
- **新消息通知**: 支持新消息通知开关、桌面通知、未读角标、设备推送 token 和设备 badge 上报。
- **通用设置**: 支持聊天背景、多语言、黑暗模式、远程配置和版本更新检查。

## 6. 扫码、举报、组织与工作台 (QR, Report, Organization & Workplace)

### 6.1 扫码能力
- **扫一扫入口**: 消息列表/联系人入口需要保留扫一扫，解析用户二维码、好友 vercode、群二维码、扫码登录和扫码入群。
- **扫码登录授权**: Web 登录二维码由手机端扫描和确认，PC/Web 端轮询状态并完成登录。
- **扫码入群**: 群二维码有效期、邀请确认开关、扫码加入和 H5 确认页需完整保留。

### 6.2 举报与投诉
- **用户/群投诉**: 好友资料、群资料和会话菜单应提供投诉入口。
- **举报类别**: 从服务端加载多语言举报类别树。
- **举报提交**: 支持举报描述、上传举报图片、提交频道 ID 和频道类型。

### 6.3 组织架构
- **组织选择器**: 原 Contacts 包包含组织架构建群入口，可从已加入组织与部门树中选择成员发起群聊。
- **组织消息**: 支持加入组织系统消息的解析和展示。
- **降级策略**: 当前本地服务端目录未检出组织模块时，Vue 版应通过功能开关隐藏入口，不能影响普通联系人和建群流程。

### 6.4 工作台
- **工作台首页**: 支持横幅、分类、用户已添加应用和常用应用记录。
- **应用管理**: 支持添加/删除用户应用、调整应用顺序、记录/删除使用记录。
- **资源类型**: 工作台横幅和应用图标使用文件模块的 `workplacebanner` 与 `workplaceappicon` 类型。

## 7. 机器人、开放平台与音视频信令 (Bot, OpenAPI & RTC)

### 7.1 机器人
- **机器人菜单**: 支持同步机器人菜单并在会话中触发。
- **行内搜索**: 支持机器人 `inline_query` 与结果回填。
- **机器人事件**: 支持机器人事件拉取、ACK、发送消息、输入中、流式消息 start/end。
- **系统机器人**: 原服务端会初始化系统机器人，频道资料需识别 `robot` 标识。

### 7.2 开放平台与第三方登录
- **OpenAPI 授权**: 支持获取 authcode、access_token 和 userinfo。
- **第三方登录**: 原服务端包含 GitHub/Gitee 登录和第三方授权状态接口；重构登录模块需保留扩展点。

### 7.3 音视频与 RTC 信令
- **信令消息类型**: 原前端定义了 `rtcData`、接受、拒绝、挂断、取消、未接听、切换音视频和通话结果等消息类型。
- **通话状态展示**: 会话消息流需能展示音视频通话结果，Electron 主进程需保留来电通知分支。
- **频道呼叫状态**: 频道信息返回的 `call_info`、在线数、signal 状态需用于会话头部或通话入口状态。

## 8. PC/Electron 客户端能力 (Desktop Shell)

- **多端形态**: 原 README 明确支持 Web、Mac、Windows、Linux；Vue 重构不应只按浏览器形态设计。
- **原生通知**: Electron 主进程负责普通消息通知、来电通知、通知点击回到对应会话。
- **托盘与未读数**: 支持托盘、窗口唤起、总未读数同步到系统角标。
- **快捷键**: 保留截图/全局快捷键、开发者工具快捷键和 ESC 退出全屏等 PC 端交互。
- **自动更新**: 保留 `common/pcupdater` 和 Electron updater 事件链路，展示可用更新、下载进度、下载完成和错误状态。
