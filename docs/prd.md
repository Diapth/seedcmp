# AgentHub PRD文档

## 比赛推荐内容

### 目标

- 构建以IM聊天为核心的多agent协作平台
- 需要支持单聊、群聊及@指定Agent


### 核心功能要求
- 需要接入 至少两个主流Agent平台（这里内定`Claude`, `Codex`）
- Agent回复的 内联产物 需要支持**预览与编辑**
- 产物包括 网页、 文档、 代码 并支持部署
- 需考虑 `多端支持` (Web、 桌面、 移动端)


### 主Agent与调度
- 主Agent扮演 `PM角色` 进行任务协调
- 负责 `理解需求`、`拆解任务并派发`
- 支持`并行调度`、`失败降级`与`冲突处理`
- 实现Agent间`上下文平滑切换与传递`


## 项目目标拆解（粗粒度）
- [ ] 实现一个IM聊天的网页端(包括前后端)，可正常使两个用户聊天及多个用户群聊
- [ ] 实现将智能体接入到网页对话，形成一个用户，且保证可正常群聊@
- [ ] 实现 PM 角色智能体，可正常和其他智能体沟通交流
- [ ] 实现多角色智能体库，不同角色智能体skill库不同，进行分工

### AI项目目标拆解（粗粒度）

- [ ] IM 聊天系统：用户、会话、消息、私聊、群聊、@、实时通信
- [ ] Agent 接入系统：把 Codex / Claude 接入为聊天用户，支持收发消息、日志读取、错误处理
- [ ] 多 Agent 协作系统：PM Agent 拆解任务，多角色 Agent 分工执行，支持上下文传递
- [ ] 任务运行系统：用 TaskRun / TaskStep 记录一次需求的执行过程、状态、日志和失败原因
- [ ] 产物系统：保存、预览、编辑 Agent 生成的网页、代码、文档等 Artifact
- [ ] 演示闭环：完成一个从聊天发起需求到多 Agent 协作再到产物预览/编辑的完整 Demo


## 项目目标拆解（细粒度）
- [ ] 实现统一消息与会话模型，支持私聊、群聊、@、消息状态、历史记录持久化
- [ ] 实现 Agent 适配器层，统一封装 Codex / Claude 等智能体的消息发送、回复解析、日志读取、错误处理
- [ ] 实现任务运行机制 TaskRun，将用户的一次需求拆成多个可追踪步骤
- [ ] 实现智能体运行日志与状态展示，包括运行中、成功、失败、超时、重试、取消
- [ ] 实现上下文管理，支持会话历史、关键消息 pin、任务上下文传递给不同 Agent
- [ ] 实现产物中心 Artifact Center，保存 Agent 生成的代码、网页、文档等产物
- [ ] 实现产物预览能力，至少支持网页预览、Markdown/文本预览、代码文件查看
- [ ] 实现产物编辑能力，至少支持代码编辑、Diff 查看、重新提交给 Agent 修改
- [ ] 实现工作区隔离，每个任务拥有独立文件目录，避免多个 Agent 产物互相污染
- [ ] 实现权限与安全控制，包括命令执行确认、文件访问限制、敏感日志脱敏
- [ ] 实现失败降级与人工接管，当 Agent 失败时允许重试、换 Agent、手动编辑
- [ ] 实现基础 Demo 流程，从用户输入需求到多 Agent 协作再到产物预览完整跑通


## 问题

### 如何给codex发送消息，且读取到codex的日志
- 怎么给 Codex 发送消息：走 CLI、API、还是子进程封装。
- 怎么保持会话上下文：每次新开进程，还是复用 session。
- 怎么读取日志：stdout、stderr、事件流、文件日志- 怎么统一收集。
- 怎么区分普通回复、工具调用、文件变更、错误、运行状态。
- 怎么取消、重试、超时、恢复。
- 怎么避免把敏感信息、内部推理、密钥写进可见日志。

这里最好抽象成统一的 AgentAdapter，否则 Claude、Codex、OpenCode 每接一个都会变成特例。
